# VKinder - бот для знакомств ВКонтакте

Бот для поиска потенциальных партнёров для знакомств на основе данных из ВКонтакте.

## Описание

VKinder — это чат-бот для социальной сети ВКонтакте, который помогает находить людей для знакомств на основе заданных критериев (возраст, пол, город). Бот показывает анкеты с фотографиями, позволяет добавлять понравившихся людей в избранное и просматривать список сохранённых анкет.

## Функциональность

- 🔍 **Поиск кандидатов** по заданным критериям
- ➡️ **Просмотр анкет** с фотографиями
- ❤️ **Добавление в избранное** (сохранение в базу данных)
- 📋 **Просмотр списка избранного**
- 🛡️ **Защита от дублей** сообщений

## Команды бота

| Команда | Описание |
|---------|----------|
| `поиск` | Начать поиск кандидатов |
| `следующий` | Показать следующего кандидата |
| `в избранное` | Добавить текущего кандидата в избранное |
| `избранное` | Показать список избранных |
| `стоп` | Остановить текущий поиск |

## Установка и запуск

### Требования

- Python 3.10 или выше
- PostgreSQL 14 или выше
- Группа ВКонтакте с токеном доступа
- Пользовательский токен ВКонтакте

### Шаг 1: Клонирование репозитория

git clone https://github.com/basova6928-sudo/vkinder.git
cd vkinder

### Шаг 2: Создание виртуального окружения

python -m venv .venv
.venv\Scripts\activate      # Windows
source .venv/bin/activate   # Linux/Mac

### Шаг 3: Установка зависимостей

pip install -r requirements.txt

### Шаг 4: Настройка переменных окружения

Создайте файл .env в корне проекта:

# Токены ВКонтакте
GROUP_TOKEN=ваш_токен_группы
USER_TOKEN=ваш_пользовательский_токен
GROUP_ID=id_группы

# Настройки базы данных PostgreSQL
DB_NAME=имя_базы_данных
DB_USER=пользователь
DB_PASSWORD=пароль
DB_HOST=localhost
DB_PORT=5432


### Шаг 5. Инициализация базы данных
Поскольку SQL‑запросы для создания таблиц вынесены в отдельный файл, выполните их одним из удобных способов:

Через psql:

psql -h DB_HOST -p DB_PORT -U DB_USER -d DB_NAME -f create_tables.sql
(при выполнении будет запрошен пароль от БД).

Через DBeaver:

Откройте файл create_tables.sql в интерфейсе вашей СУБД.
Выполните все запросы из файла в контексте нужной базы данных.
